# Statlog (German Credit Data)

Dataset of the article's credit-scoring case (WP4). The archive is kept as
downloaded; the pipeline reads `german.data` from it and checks the digests
below before training.

| Item | Value |
| --- | --- |
| Source | UCI Machine Learning Repository, dataset 144: https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data |
| Creator | Hans Hofmann, Universität Hamburg |
| DOI | 10.24432/C5NC77 (to confirm on the UCI page) |
| Licence | CC BY 4.0, as stated by UCI for this dataset (to confirm on the UCI page) |
| Downloaded by | Davide Carneiro, 2026-10-12, from the UCI page; added to the repository the same day |
| Instances | 1,000; 20 attributes (7 numerical, 13 categorical); label 1 = good, 2 = bad credit risk |
